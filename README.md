# BB Zone - Flutter Booking App
A Flutter-based booking application with clean UI, authentication, and booking management features.
## Features
- User Authentication
- Booking Management
- Date Picker
- Firebase Integration
- Responsive UI
- State Management
  ## Tech Stack
- Flutter
- Dart
- Firebase
- Provider / GetX / Bloc
lib/
 ├── screens/
 ├── widgets/
 ├── services/
 ├── models/
 └── main.dart
## Architecture
The app follows clean architecture principles with separated layers:
- UI Layer
- Service Layer
- Data Layer
